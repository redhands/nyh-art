# Instagram Import Guide

이 폴더는 인스타그램에 올린 그림을 홈페이지용 아카이브로 옮길 때 사용합니다.

## 사용 방법

1. 인스타그램 게시물 이미지를 내려받아 이 폴더에 넣습니다.
2. 이미지와 같은 이름의 `.md` 파일을 만듭니다.
3. 아래 형식으로 작품 정보를 적습니다.
4. 루트에서 `npm run build:data`를 실행합니다.

## 예시

이미지 파일:

`post-2026-03-25-01.jpg`

설명 파일:

`post-2026-03-25-01.md`

```md
---
title: 해파리와 별빛
subtitle: 인스타그램 기록 01
size: 디지털
medium: Procreate
year: 2026
description: 인스타그램에 공개한 디지털 드로잉 작업입니다.
---

별빛이 닿는 바다를 상상하며 그린 디지털 작업.
```

## 권장 규칙

- 파일명은 영문, 숫자, 하이픈 위주로 단순하게 씁니다.
- 인스타 캡션 전체를 그대로 옮기기보다 홈페이지용 설명으로 짧게 다듬는 것이 좋습니다.
- 여러 장을 한 게시물에서 가져올 경우 `-01`, `-02` 같은 번호를 붙이면 관리가 쉽습니다.
